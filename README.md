# Designing Sound for an Exhibition Experience

An interactive participant guide for exploring sonic design through the **Monet and Chicago** exhibition walkthrough.

## Workshop focus

How might sonic design support engagement with an art exhibition while leaving room for individual interpretation and visitor control?

Participants explore the exhibition visually, create an instrumental audio prototype, and refine their sonic choices after learning more about the art. Sound and silence are both valid design choices. No music-production experience is required.

## Activity

1. Open the audio-generation tool and exhibition walkthrough.
2. Explore the exhibition without sound.
3. Write descriptive words for one minute, select three priorities, and record baseline ratings.
4. Generate and download an instrumental track.
5. Experience the video with the track and reflect on its fit.
6. Read the exhibition context and revisit the paintings.
7. Keep, revise, replace, or remove the soundtrack.
8. Test the final choice and consider where sound or silence belongs.
9. Download written responses and upload the requested files to the facilitator's collection folder.

## Using the guide

Open the published GitHub Pages website, or open `index.html` locally in a browser. Headphones are recommended but optional. Keep the walkthrough muted while testing generated sound.

The guide includes response fields, a one-minute timer, and an answer-file download. Responses are saved locally in the browser where storage is available. They are not sent automatically to GitHub or the facilitator. Download answers before closing the page and upload files manually as instructed.

Suno requires sign-in and sufficient generation/download access. Ask the facilitator for workshop access if needed. Shared credentials are intentionally excluded from this public version.

## Publication

This repository contains a static website with no build dependencies. In **Settings > Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. The entry file is `index.html`.

## Scope

The walkthrough is a remote reference for a physical exhibition. This repository contains the participant guide, not participant responses, audio submissions, or research findings. The linked Google Drive collection folder has its own access settings.
